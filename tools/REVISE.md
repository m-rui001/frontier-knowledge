# 精修简报：去掉"AI 味"但也别把文章改死

## 背景

16 篇稿子已经写完，信息量没问题。问题在**腔调**：句子结构重复、每段都在"拔高"、比喻成套。
但注意——这些句式本身都是正常汉语，问题在**密度和功能**（同一个套路反复用来把常识包装成洞见）。
所以这一轮只做**减法与替换**，不重写、不增删小节、不改变已有判断。改完汉字数应与原来相差不超过 ±10%。

## 六条具体规则

1. **"不是 A，而是 B" / "不在于 A，而在 B" / "X 不是 A，是 B"**
   全文最多保留 **1 处**，放在最核心的那个论点。其余全部改成直陈：直接说 B，把 A 删掉；
   或者改成让步："A 的说法也有道理，但这里 B 才是真的"。
   反例（要改）："八分钟带来的不是省钱，是形态变化" → "八分钟带来的是形态变化：预报从一天两次的批处理，变成按需伸缩的服务。"

2. **"真正的 X" / "本质上" / "说到底"**
   全文最多 **1 处**。其余删掉限定词即可：'天气预报真正要卖的是范围' → '天气预报要卖的是范围'。

3. **极值词**（最硬、最值钱、最该、最要紧、最贵、最强、最大）
   全文最多 **2 处**，且每一处后面必须紧跟依据（数字、对照、失败案例）。没有依据的，降级成普通形容词。

4. **格言式收尾**
   每节结尾不要都落一句短促的断言（"后者才是自主性的真门槛。" "读的时候别混。"）。
   全文最多留 **2 处**；其余小节改成用事实、数字、或论文里的原话收尾。

5. **比喻**
   一篇只留 **1 个**主隐喻（天花板 / 地基 / 护城河 / 账本 / 闸门 / 漏斗 / 搬家 等选一个），
   其余全部换成直白说法。"瓶颈搬家"→"瓶颈转移到湿实验"；"护城河被抹平"→"这一类工具不再有独立价值"。

6. **禁止自我导航与讲课腔**
   删掉"后面会讲""前面说过""读的时候别混""先看清它证明了什么""这一点很重要"。
   删掉"一是…二是…三是…"和"第一…第二…第三…"这种清单化罗列，改成连贯段落；全文最多保留一次。

7. **小节标题去同构**
   现在 16 篇的小节标题几乎都是"动词短语＋逗号＋判断"的同一种句式。至少把其中一半改成陈述句或名词短语。
   例："把坐标回归换成从噪声里捡原子" → "扩散头取代坐标回归"；"和谁比，赢多少" → "对 ENS 的逐目标胜负"。

## 不要做的事

- 不要新增事实、数字、判断。
- 不要动 `src`、`url`、`meta`；`ratio` 保持原样（脚本会回填）。
- 不要改 `typst/lib.typ` 或别人的文件。
- 不要为了去味把句子改得干瘪：该有的口语节奏、破折号停顿、反问，保留一部分——
  **每千字 2 到 4 个破折号是正常汉语，超过 6 个才是毛病。**
- 不要碰段首首行缩进、标点全半角之类排版问题。
